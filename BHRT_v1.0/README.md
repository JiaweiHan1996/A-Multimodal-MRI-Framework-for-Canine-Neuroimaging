# Beagle High Resolution Template (BHRT)

**Version:** 1.0  
**Update:** 2026-09-22

---

## Introduction

BHRT is a high-quality beagle brain template.

---

## Files

### T1w Template

- `BHRT_T1w_0.5mm.nii.gz` — T1w template
- `BHRT_T1w_brain_0.5mm.nii.gz` — T1w template with brain tissues only

### T2w Template

- `BHRT_T2w_0.5mm.nii.gz` — T2w template
- `BHRT_T2w_brain_0.5mm.nii.gz` — T2w template with brain tissues only

### Myelin Map

- `BHRT_MyelinMap_0.5mm.nii.gz` — Myelin map
- `BHRT_MyelinMap_brain_0.5mm.nii.gz` — Myelin map with brain tissues only

### Brain Mask and Tissue Segmentation

- `BHRT_BrainMask_0.5mm.nii.gz` — Whole brain mask
- `BHRT_TissueSegment_0.5mm.nii.gz` — Three types of brain tissues (CSF = 1, GM = 2, WM = 3)
- `BHRT_TPM_0.5mm.nii.gz` — Tissue probability maps with three types
- `BHRT_TPM_CSF_0.5mm.nii.gz` — Tissue probability map of CSF
- `BHRT_TPM_GM_0.5mm.nii.gz` — Tissue probability map of GM
- `BHRT_TPM_WM_0.5mm.nii.gz` — Tissue probability map of WM

### Cortical and Subcortical Atlas

- `BHRT_atlas_cort+subcort_0.5mm.nii.gz` — Cortical and subcortical atlas
- `Label_BHRT_atlas_cort+subcort.txt` — Label information of cortical and subcortical atlas

### White Matter Atlas

- `BHRT_atlas_wm_0.5mm.nii.gz` — White matter atlas
- `Label_BHRT_atlas_wm.txt` — Label information of white matter atlas

### Lobe Atlas

- `BHRT_atlas_lobe_0.5mm.nii.gz` — Lobe atlas
- `Label_BHRT_atlas_lobe.txt` — Label information of lobe atlas
