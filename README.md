# Introduction

This repository contains the following six components.

1. **`BHRT_scripts`**  
   Scripts for creating high-resolution templates.

2. **`BHRT_v1.0`**  
   A high-quality beagle brain template, including high-resolution T1w and T2w images and Tissue Probability Maps (TPM) files, etc.

3. **`dmri`**  
   Diffusion MRI preprocessing scripts, supporting distortion correction and eddy current correction, etc.

4. **`example data`**  
   Example dataset containing 3D T1w and T2w data with 0.5 mm isotropic voxels.

5. **`fmri`**  
   Functional MRI data preprocessing scripts, supporting reorientation, motion correction, and multi-echo data combination, etc.

6. **`smri`**  
   Structural MRI data processing scripts, supporting VBM (Voxel-Based Morphometry) analysis.

> **Note:** BHRT stands for **Beagle High-Resolution Template**.
