# dMRI Preprocessing Pipeline with TOPUP and EDDY (FSL)

This README describes the dMRI preprocessing script `dmri_preprocessing.sh`.

## Requirements

- FSL must be installed in advance.
- Make sure FSL commands such as `topup`, `eddy`, `dtifit`, and `eddy_quad` are available.
- The FSL environment should be properly configured, for example `FSLDIR`.

## What the Script Does

The script performs:

- Susceptibility distortion correction using blip-up / blip-down b0 images (TOPUP)
- Eddy current and motion correction (EDDY)
- Optional DTI fitting (`dtifit`)
- Quality control outputs such as `qc.pdf` and `eddy_quad` results

## Usage

Before running the script, grant execute permission:

```bash
chmod a+x dmri_preprocessing.sh
```

Run the script:

```bash
./dmri_preprocessing.sh -i <forward> -r <reverse> -t <esp_ms> -p <PE_dir> -b <bval> -v <bvec> -L <outdir> [-o <output>] [-y <yes/no>]
```

Example:

```bash
./dmri_preprocessing.sh -i forward.nii.gz -r reverse.nii.gz -t 0.5 -p PA -b dwi.bval -v dwi.bvec -L ./outdir
```

## Arguments

- `-i <forward>` (required): Forward image, e.g. blip-up DWI.
- `-r <reverse>` (required): Reverse image, e.g. blip-down DWI.
- `-t <esp_ms>` (required): EPI echo spacing in milliseconds.
- `-p <PE_dir>` (required): Phase-encoding direction: AP, PA, RL, or LR (for the forward image).
- `-b <bval>` (required): b-value file.
- `-v <bvec>` (required): b-vector file.
- `-L <outdir>` (required): Output directory (will be created).
- `-o <output>` (optional): Output filename (default: preprocessed_dwi.nii.gz).
- `-y <yes/no>` (optional): Whether to perform DTI fitting (yes/no, default: yes).

## Output

After the script finishes, it creates the following contents under `<outdir>`:

- `<outdir>/results/`
  - Preprocessed dMRI data, `bval`, `bvec`, `mask`, and `qc.pdf`.
- `<outdir>/eddy_quad/`
  - Results generated by FSL `eddy_quad`.
- `<outdir>/dti_results/`
  - DTI fitting results.
- `<outdir>/dwi_preproc_tmp/`
  - All intermediate files produced during preprocessing. This directory can be deleted if not needed.
- `<outdir>/preproccessing.log`
  - Log generated during script execution.

## Notes

- Ensure FSL is installed and configured before running the script.
- The forward and reverse images should come from the same subject and should have matching acquisition parameters except for the phase-encoding direction.
- `-p <PE_dir>` must match the actual phase-encoding direction; otherwise, TOPUP / EDDY results may be incorrect.
- Check that the number of volumes in the DWI data matches the `bval` and `bvec` files.
- `dwi_preproc_tmp/` stores intermediate results. After verifying the final outputs, you can delete it to save disk space.
- Check the actual log filename produced by the script if it differs from the example above.
